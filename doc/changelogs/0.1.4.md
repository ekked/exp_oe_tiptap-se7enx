# exp_oe_tiptap 0.1.4

The editor does what the Online Editor's TinyMCE does: tag and row properties, "Apply to" in the cell dialog, paste
cleanup, a context menu, find and replace, a full help, an editable source view and the non-breaking space. From
pull request #2, refined on merge.

## Added

- Added: Tag properties (button `tag_props`, or a click on a tag of the path): the class and custom attributes of
  paragraphs, headings, lists, list items, strong and emphasize, from content.ini, as ezoe's tag dialogs.
- Added: Table row properties (button `row_props`): the class and custom attributes of a row (content.ini [tr]).
- Added: "Apply to" in the table cell dialog: the cell, its row, its column, all cells of the table, or the selected
  cells; each cell keeps its own span.
- Added: Pasted Word, Google Docs and web page HTML is cleaned to what a text field stores, parsed in an inert
  document: scripts, styles, event handlers, images and unknown markup go, only http(s), mailto, tel, ftp and
  relative links stay. "Paste as text" (button `pastetext`, Ctrl+Shift+V).
- Added: A context menu with the commands at the cursor (right click, the context menu key, Shift+F10), a WAI-ARIA
  menu: arrows, Home and End move, Escape returns to the text. `[EditorSettings] ContextMenu`.
- Added: Find and replace (Ctrl+F, buttons `search` and `replace`), the count in a live region.
- Added: The help in tabs (toolbar, keyboard, tags, tips, about); shortcuts are named as the platform names them.
- Added: The source view (button `code`), editable by default (`[EditorSettings] SourceEditable`): Apply cleans the
  HTML as a paste does, lists what the editor cannot keep and asks first. The server still makes the stored text
  with eZOEInputParser, which drops scripts, event handlers and styles and refuses script links.
- Added: The non-breaking space (button `nonbreaking`, Ctrl+Shift+Space).
- Added: Tests: the new dialogs through the editor and eZOEInputParser (stored ezxml identical after three passes),
  the server's refusal of scripts typed into the source view, and the text's language tag.

## Updated

- Updated: Empty paragraphs no longer grow with every save or editor switch; a table is posted in a paragraph of its
  own. A table after a line of block embeds is posted without one, so the first embed is stored without the
  placeholder text "ezembed" (found on merge: 1 fixture lost it).
- Updated: The text's `lang` is the language tag of its locale (de-DE, from the locale file's ContentLanguage),
  no longer the first part of the locale code (`ger`), which is no valid tag.
- Updated: Skin o2k7's toolbar buttons stand 24px apart, the search bar's controls and the context menu's items are
  24px high (WCAG 2.5.8 target size).
- Updated: The status bar keeps the space after "Path:"; "Editing with" gives way to ezoe's one-group engine switch.
- Updated: Every new text is translated (ger-DE) and in the untranslated template.
