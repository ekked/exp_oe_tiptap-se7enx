# exp_oe_tiptap 0.1.2

Custom tags in Tiptap follow two new settings of the Online Editor in Exponential 6.0.15: the custom tag
controls and hidden custom tags. Both were rebuilt from LoveStack, Mugo Web's distribution of the same kernel, with
thanks to Mugo Web.

## Added

- Added: Custom tag controls, with `ezoe.ini [EditorSettings] CustomTagControls=enabled` (the template passes it as
  `options.customTagControls`). When the selection is in a custom tag, a bar on the tag offers: move up, move down
  (block custom tags), edit (the custom tag dialog) and remove (the tag goes, its content stays). The same from the
  keyboard: Alt+Shift+Up, Alt+Shift+Down, Alt+Shift+E, Alt+Shift+Delete. Backspace in an empty block custom tag
  replaces it with an empty paragraph, and every block custom tag shows its name (`CustomTagsDescription[]`) as a
  label. The controls work through ProseMirror transactions and the bar lies outside the editable content, so
  nothing of them reaches the saved text. Rebuilt from LoveStack commit 63334f1681 (the `custom_tags_controls`
  plugin, Copyright 2014, Mugo Web).
- Added: The custom tag dialog shows a tag's example image, `images/editor/custom_tags_thumbs/<name>.png` in one of
  the site's designs (the definition key `preview`).
- Added: Tests for the controls and the tag list (`tests/js/ui/customtag-controls.test.mjs`).

## Updated

- Updated: The custom tag dialog does not offer the tags `content.ini [CustomTagSettings] IsHidden[]` names for a
  new tag (definitions with `hidden: true`); a hidden tag already in the text keeps its name in the dialog and can
  still be edited. Rebuilt from LoveStack commit e21ef46691.
- Updated: The German translation and the untranslated template have the texts of the controls.

## Upgrading

Both settings come with Exponential 6.0.15's ezoe; with an older ezoe the definitions carry neither `hidden` nor
`preview` and the controls stay off, so the editor behaves as in 0.1.1. The controls are off unless
`CustomTagControls=enabled` is set; new Exponential installations set it.
