# exp_oe_tiptap 0.1.11

A siteaccess in the admin design admin4 or admin4l gets Tiptap in admin4's look (skin `a4`) without a setting of its
own.

## Added

- Added: `[EditorSettings] DesignSkin[]`, the skin for a design, used when `Skin` is not set or empty, looked up with
  `site.ini [DesignSettings] SiteDesign`. The extension sets `DesignSkin[admin4]=a4`. Before, an admin4 siteaccess
  without `Skin=a4` showed the editor in ezoe's look (o2k7, TinyMCE 3's toolbar and icon sprite) inside admin4.
  `Skin` still decides first; `Skin=o2k7` keeps ezoe's look in admin4.
- Added: `DesignSkin[admin4l]=a4`: admin4l draws the admin page from layouts with admin4's markup and stylesheets, so
  an admin siteaccess on admin4l gets the same look.
- Added: `SettingsDefaultsTest` checks the defaults and the order in the template.
