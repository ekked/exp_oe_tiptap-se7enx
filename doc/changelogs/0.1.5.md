# exp_oe_tiptap 0.1.5

A text in a right-to-left content language (Hebrew, Arabic, Persian, Urdu ...) is edited right to left.

## Added

- Added: The option `contentDirection` ('rtl' or 'ltr'): the editable text gets `dir="rtl"` for a right-to-left
  language, nothing for a left-to-right one, which keeps the direction of the page. The edit template passes the
  `text_direction` of the text's locale (the locale file's `[LanguageSettings] TextDirection`, Exponential 6.0.15);
  with an older kernel the attribute is missing and the text stays left to right.
- Added: Tests of the attribute.
