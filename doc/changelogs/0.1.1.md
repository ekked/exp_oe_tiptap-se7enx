# exp_oe_tiptap 0.1.1

Tiptap becomes an engine of the Online Editor's editor registry, and the two switches of 0.1.0 become one. The
owner's decision 5 of [plan.md](../plan.md#6-decisions-for-the-owner) is resolved: Tiptap shows up in ezoe's engine
registry, next to TinyMCE 3 and 8, and is chosen like them.

## Added

- Added: The ezoe engine `tiptap` (`expOETiptapEngine`), registered from the extension's own
  `settings/ezoe.ini.append.php` (`[EditorSettings] Engines[tiptap]=expOETiptapEngine`). ezoe's page `/ezoe/engine`
  lists it with its name, version (the extension's), description and status, and offers it in its select; it is
  available while the built bundle is present, otherwise ezoe hides it and falls back to TinyMCE.
- Added: `bin/php/migrate_editor_preference.php`, which moves the 0.1.0 preference `exp_oe_editor` of every user to
  ezoe's `ezoe_engine` (`--dry-run` shows what it would do).
- Added: The engine's name and description in ezoe's translation context (`design/standard/ezoe`), German and the
  untranslated template.
- Added: Tests for the registration, the engine's details, the translation between ezoe's engines and the two
  editors, the migration and the target of Tiptap's switch button.

## Updated

- Updated: One choice of editor, ezoe's: the user preference `ezoe_engine` (the page `/ezoe/engine`, or the
  "Switch to the editor ..." buttons below a text field), then `ezoe.ini [EditorSettings] EditorEngine` of the
  siteaccess. Choosing Tiptap anywhere shows Tiptap, choosing TinyMCE shows TinyMCE. TinyMCE stays the default
  unless `EditorEngine=tiptap` is set.
- Updated: ezoe's switch buttons are on with this extension (`EngineSwitch=enabled` in its `ezoe.ini.append.php`),
  as the 0.1.0 switch was; Tiptap shows them below its field, with "Editing with Tiptap", and its toolbar's switch
  item clicks the button to the site's TinyMCE.
- Updated: The edit template is ezoe's own `ezxmltext_ezoe.tpl`, which includes the Tiptap template for the engine
  `tiptap`; `ezxmltext_exp_oe_tiptap.tpl` only passes on to it. The Tiptap template reads its settings from the
  engine config (`$input_handler.engine.config`).
- Updated: The 0.1.0 preference `exp_oe_editor` is moved to `ezoe_engine` the first time a user opens an edit form:
  `tiptap` becomes `ezoe_engine=tiptap` (that user saw Tiptap in 0.1.0 whatever ezoe's preference said), `ezoe`
  keeps the user's ezoe engine; the old preference is emptied.
- Updated: The 0.1.0 switch button (`CustomActionButton[<id>_exp_oe_switch_<editor>]`) and a POST to
  `exp_oe_tiptap/switch` keep working and store ezoe's preference; `exp_oe_tiptap/switch` without a POST redirects
  to `/ezoe/engine`. The policy `exp_oe_tiptap/switch` guards only that view; the buttons in the edit form follow
  ezoe's `EngineSwitch`.
- Updated: README, INSTALL (with a section on upgrading from 0.1.0), usage, configuration, architecture, extending,
  maintenance and plan describe the engine and the one switch.
- Updated: Version 0.1.1 in `ezinfo.php`, `extension.xml` and `package.json`.

## Removed

- Removed: The settings `exp_oe_tiptap.ini [EditorSettings] DefaultEditor` and `AllowSwitch`; they are no longer
  read. Use `ezoe.ini [EditorSettings] EditorEngine` and `EngineSwitch`.
- Removed: The templates `ezxmltext_exp_oe_tiptap_switch.tpl` (the 0.1.0 switch button) and `exp_oe_tiptap/switch.tpl`
  (the page of the 0.1.0 view): there is one set of switch buttons and one page, ezoe's.
- Removed: The per-request editor of 0.1.0 (`expOETiptapEditor::setRequestEditor()`, `requestEditor()`, `choose()`);
  ezoe's preference is read back in the same request.

## Requirements

Exponential 6.0.15 or later: ezoe with its editor engine registry. The version, description and status column on
`/ezoe/engine` come with the ezoe of the same Exponential version (`expOEEditor::details()`, an engine's optional
`version()` and `description()`); with an ezoe registry from before that addition Tiptap is still registered and
selectable, without that table.
PHP 8.0 or later, ezjscore and ezformtoken active; PHP curl for the AI commands. Built with Tiptap 3.31.4 (MIT
License); the built bundle is unchanged from 0.1.0.

## Upgrading

Update the files, regenerate autoloads (`php bin/php/ezpgenerateautoloads.php -e`, a new class), clear the INI,
template, template-override and translation caches, reload PHP-FPM and restart Velocity. Optionally run
`php extension/exp_oe_tiptap/bin/php/migrate_editor_preference.php -s <admin siteaccess>`. Details:
[INSTALL.md](../../INSTALL.md#upgrading-from-010).
